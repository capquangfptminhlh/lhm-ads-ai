Kết nối Google Ads và Meta Ads

Hướng dẫn tự thực hiện trên máy Windows. Chọn đúng tài khoản có quyền quản lý quảng cáo; không gửi mật khẩu hay token cho bên hỗ trợ.

Google Ads APIMeta Ads APIMCP / AIKhắc phục lỗi

1. Google Ads API trong phần mềm

  1. Đăng nhập email Google có quyền truy cập tài khoản Ads, có thể qua MCC.
  2. Truy cập Google Cloud Console, chọn/tạo dự án, bật Google Ads API và kiểm tra quyền API để đọc tài khoản thật (thường Explorer trở lên).
  3. Trong Google Auth Platform, thiết lập màn hình đồng ý, scope https://www.googleapis.com/auth/adwords và Test users nếu đang Testing.
  4. Tạo OAuth Client ID loại Desktop app tại Credentials/Clients và tải file JSON. Không dùng Service Account JSON.
  5. Trong LHM Ads AI → Tài khoản Ads → Google Ads → Cấu hình Google OAuth; ở bước 2 chọn file JSON, kiểm tra thông tin đã điền rồi bấm Lưu.
  6. Bấm Đăng nhập Google Ads, đăng nhập qua trình duyệt Google chính thức, cấp quyền, chọn Ads/MCC và bấm Kiểm tra API.

Từ 09/09/2026 Google Ads API không bắt buộc developer token; dự án Cloud vẫn phải có quyền API thích hợp. OAuth thành công chưa bảo đảm đã có quyền truy cập Ads thật.

2. Meta/Facebook Ads API trong phần mềm

  1. Truy cập Meta Business Settings kiểm tra quyền trên tài khoản quảng cáo.
  2. Mở Meta for Developers, tạo Meta App cho Marketing API/Facebook Login; yêu cầu quyền ads_read để đọc, ads_management chỉ khi cần ghi.
  3. Ở App Settings → Basic lấy App ID và App Secret; khai báo callback hiển thị trong LHM nếu Meta chấp nhận.
  4. Trong LHM Ads AI → Tài khoản Ads → Meta Ads → Cấu hình Meta App, nhập ID/Secret và lưu trên máy.
  5. Bấm Đăng nhập Meta Ads, cấp quyền trên trang Facebook chính thức, chọn tài khoản Ads và chạy Kiểm tra API.

App Live có thể cần HTTPS Redirect URI, App Review, Business Verification và Advanced Access. Không dùng thủ thuật vượt quy trình này.

3. MCP để kết nối AI

MCP của Google/Meta là kết nối cho AI client tương thích riêng. LHM Ads AI hiện có API trực tiếp nhưng chưa có máy chủ MCP hoạt động trong EXE.

  1. Google Ads: tham khảo Google Ads MCP chính thức, cấu hình Google Cloud và xác thực theo Google.
  2. Meta Ads: xem Meta Ads MCP hoặc Meta Ads AI Connectors, đăng nhập và cấp quyền đúng cho AI client.
  3. Ưu tiên quyền chỉ đọc; không dán token bí mật vào prompt hoặc file cấu hình công khai.

4. Khi kết nối gặp lỗi

Google access_denied/403
Kiểm tra email Ads/MCC, quyền Google Cloud API, Test users và màn hình đồng ý OAuth.
Google redirect_uri_mismatch
Tạo lại OAuth Client đúng loại Desktop app.
Google không thấy tài khoản
Kiểm tra quyền email đăng nhập đối với tài khoản Ads/MCC.
Meta Redirect URI không hợp lệ
Sao chép callback chính xác; kiểm tra yêu cầu HTTPS và App Review.
Meta không lấy được báo cáo
Kiểm tra quyền ads_read, account ID, hạn token và vai trò người dùng.

Hỗ trợ khách: gửi ảnh đã che email/tài khoản nhạy cảm và mã lỗi. Không gửi mật khẩu, Refresh Token, Access Token, App Secret hay file OAuth JSON.

Trong phần mềm: Tài khoản Ads → 📖 Hướng dẫn cho khách → Bắt đầu kết nối.
