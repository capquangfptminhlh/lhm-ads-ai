Kết nối AI / MCP

Sử dụng khóa riêng với phạm vi chỉ đọc hoặc cho phép tạo yêu cầu tạm dừng.

01. Tạo API key

Key được hiển thị đúng một lần. Không nhập key này vào ứng dụng hoặc nguồn không đáng tin.

API key — chỉ hiển thị lần này:

02. Kết nối MCP qua stdio

Bản starter đã có MCP chạy bằng stdio, dùng API key nội bộ. Remote HTTPS MCP “một link” cần triển khai và kiểm thử riêng.

export LHM_ADS_URL=http://127.0.0.1:8080
export LHM_ADS_API_KEY='lhm_...'
python -m ads_mcp.mcp_stdio

Công cụ MCP

list_accountsget_insightsrequest_pause_campaignlist_actions
